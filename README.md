### 🧠 Local RAG Pipeline
A Retrieval-Augmented Generation pipeline built from scratch with anti-hallucination layers, designed to run on modest local hardware.
- Pipeline: text loading → chunking → `all-MiniLM-L6-v2` embeddings → **FAISS** vector store → LLM generation
- FAISS score gating to reject low-relevance retrievals
- Evaluated with **ROUGE-L, cosine similarity, and exact match**
- **Stack:** `LangChain` `FAISS` `HuggingFace Transformers` `flan-t5-base`
